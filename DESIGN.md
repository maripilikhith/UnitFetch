# UniFetch interface

The main task is saving a video from a pasted URL. The input and next action dominate; technical setup appears only when disconnected. Downloads are a compact activity list, not a dashboard full of empty metrics.

Palette: ink `#0c1220`, panel `#151e30`, blue `#79a8ff`, violet `#b2a1ff`, text `#f3f6ff`, muted `#9caac3`. Use locally available Segoe UI Variable / Segoe UI. Display type 28 px, body 14 px, utility 12 px. Left alignment throughout.

Layout: 420 px popup, with a separate tab option using the same interface. Brand and connection indicator, two view tabs, a single link form, a contextual result, then a quiet footer. A narrow vertical activity rail echoes a file transfer path. Radius varies by hierarchy: 22 px main input surface, 12 px controls, 8 px rows.

Review: keep the requested dark blue/violet language, but remove decorative gradients, fabricated thumbnails, numerical stats, and repeated cards. The expressive element is the link intake and its blue scan action. Keyboard focus, reduced motion, accessible status updates, and real empty/error states are required.
